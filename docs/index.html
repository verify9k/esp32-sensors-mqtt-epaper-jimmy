WHY THIS PROJECT

一個完整的 IoT 顯示節點

從感測、顯示、網路傳輸到燈號控制，集中在一個容易理解與延伸的 ESP32 專案裡。

01

即時環境資料

DHT11 讀取溫度與濕度，光敏電阻讀取環境亮度，資料每 60 秒同步一次。

02

三色電子紙儀表板

使用黑、白、紅三色設計，將數值、單位與中文圖示清楚排列在 296 × 128 畫面上。

03

MQTT 雙向通訊

感測資料上傳到 MQTT，並可從控制 Topic 遠端切換三個指示燈。
